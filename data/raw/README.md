# Competition data

The files released for the ANAS Operational Cases Forecasting Challenge are not part of this repository. To run the code, copy them into this folder with these names:

| File | Used by | Content |
|---|---|---|
| `train.csv` | final pipeline, experiments | One row per registered operational case, 2016–2023. |
| `test.csv` | final pipeline, experiments | The road–month pairs to predict, 2024–2025. |
| `road_metadata.csv` | final pipeline, experiments | Static road characteristics and 2024/2025 annual case counts by type. |
| `incidenti.xlsx` | experiments only | Accident records for a subset of roads. |
| `example_submission.txt` | experiments only | Reference for the submission format. |

Everything in this folder except this file is ignored by git.
